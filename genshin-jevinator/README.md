# 原神ジェビネーター

原神のキャラを当てるゲーム。118人・98問。
**GitHub Pages で遊べます → https://kotenbu135.github.io/artifacts/genshin-jevinator/**

完全に静的で、遊んでいる間はネットワークを使いません。APIキーも要りません。

## 中身

| ファイル | |
|---|---|
| `index.html` | ページ本体。ベイズ更新と期待情報利得の計算をJSでやる |
| `data.js` | 118キャラ × 98問の知識表（自動生成。手で編集しない） |

`data.js` は元のプロジェクト側の `export_web.py` が書き出します。

## 知識表の作り方

質問98問を2つに分けています。

- **客観29問**（元素・武器種・出身・レアリティ・体型・実装時期）
  → 公式データから機械的に。出典は [Project Amber](https://gi.yatta.moe/)。日本語名も公式のもの。
- **主観69問**（髪の色・服装・性格・戦闘での役割・人気）
  → [Jev](https://typesafe.ai/)（判断専用の小さなモデル）に聞く。
  118人×69問＝8,142判断を3.3秒で埋めました。

分けたのは、**Jevの知識が2024年秋で止まっている**と測って分かったからです。

| Jevの正答率 | 元素 | 武器 | 出身 | 星5 |
|---|---|---|---|---|
| 2024年9月までの87人 | 80.5% | 69.0% | 83.9% | 83.9% |
| 2024年10月以降の31人 | 9.7% | 32.3% | 32.3% | 41.9% |
| でたらめに答えた場合 | 14% | 20% | 12% | 57% |

新しいキャラでは、でたらめより低い。しかも「知らない」とは言わず、
名前の字面に引っぱられて自信を持って間違えます（コロンビーナ→風、オデット→水）。
なので正解が手に入る事実はJevに聞かず、データベースから入れました。

全118人を1人ずつ出題した結果:

| 表 | 1回目の推測で正解 | 平均質問数 |
|---|---|---|
| 公式データ＋Jev | 118/118 | 7.1 |
| 98問ぜんぶJev | 80/118 | 14.2 |

ページ内の「Jevに全部任せた表で遊ぶ」モードで、後者の壊れかたを実際に試せます。
