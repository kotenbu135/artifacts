# 原神ジェビネーター — 作った過程と評価コード

ブラウザ版は [../](../) にあります。このディレクトリは表を作り、精度を測るための Python 一式です。

原神のキャラ当てゲーム。118人・98問。
前作（一般常識版のジェビネーター）と同じ骨だが、**ここでは知識表をJevに任せると壊れる**ことが分かり、
そこを測って作り直した記録でもある。

## いちばん大事な発見: Jevの原神知識は2024年秋で止まっている

元素・武器種・出身・レアリティ・体型には客観的な正解があるので、正面から突き合わせられる。
正解データは公式データのミラー（gi.yatta.moe / Project Amber）から取った 118人ぶん。
日本語名も公式のものをそのまま使っている。

Jevに「このキャラの元素は？」と聞いた正答率（`knowledge_check.py`）:

| 聞き方 | 元素 | 武器 | 出身 | 体型 | 星5 |
|---|---|---|---|---|---|
| 日本語名だけ | 51.7% | 42.4% | 60.2% | 45.8% | 57.6% |
| 英語名だけ | 65.3% | 56.8% | 69.5% | 63.6% | 71.2% |
| 日本語名＋英語名 | 61.9% | 59.3% | 70.3% | 62.7% | 72.9% |
| （でたらめに答えた場合） | 14% | 20% | 12% | 20% | 57% |

**英語名を足すと当たるようになる。** Jevの原神知識は英語で入っている。

そして実装時期で切ると、正体がはっきり出る:

| | 元素 | 武器 | 出身 | 体型 | 星5 |
|---|---|---|---|---|---|
| 2024年9月までの87人 | **80.5%** | 69.0% | 83.9% | 71.3% | 83.9% |
| 2024年10月以降の31人 | **9.7%** | 32.3% | 32.3% | 38.7% | 41.9% |

新しいキャラの元素は **9.7%、でたらめ（14%）より低い**。
コロンビーナを風、オデットを水、兹白を草と答える。知らないのではなく、
名前の字面から引っぱられて自信たっぷりに間違える。

## だから、表の埋め方を2つに分けた

| | 質問数 | 誰が埋めるか |
|---|---|---|
| 客観質問（元素・武器・出身・星・体型・実装時期） | 29問 | **公式データから機械的に**。Jevには聞かない |
| 主観質問（見た目・髪・服装・性格・役割・人気） | 69問 | **Jev**。公式データには無いのでここが本番 |

「算術はコードに置く」と同じ理屈で、「正解が手に入る事実はデータベースに置く」。
Jevの持ち場は、正解が存在しないほうの69問。

## 測った結果

全118人を1人ずつ出題（`gautoplay.py`）。出題者役は「そのキャラをよく知っているプレイヤー」で、
客観質問には公式データから正確に答え、主観質問には表を作ったのとは別の聞き方でJevが答える。

| 表 | 1回目の推測で正解 | 3回以内 | 平均質問数 |
|---|---|---|---|
| **公式データ＋Jev（本番）** | **118/118 (100%)** | 118/118 | **7.1** |
| 98問ぜんぶJev（比較） | 80/118 (68%) | 91/118 (77%) | 14.2 |

実装時期で切ると差の出どころがはっきりする（`era_breakdown.py`）:

| 表 | 2024年9月までの87人 | 2024年10月以降の31人 |
|---|---|---|
| 公式データ＋Jev | 100% | **100%** |
| 98問ぜんぶJev | 83% | **26%** |

出題者の返事が壊れる場合:

| ノイズ | 本番の表 1回目 | 3回以内 | 全部Jevの表 3回以内 |
|---|---|---|---|
| 0% | 100% | 100% | 77% |
| 15% | 74% | **100%** | 70% |
| 30% | 42% | 78% | 53% |

### 新しいキャラを1人足すのに要るもの
表から8人（胡桃・ナヒーダ・雷電将軍・鍾離・コロンビーナ・オデット・ファルカ・リンネア）を抜いて実演（`learn_new.py`）:

```
抜いた状態 0/8  →  公式データ6項目 ＋ Jevに1リクエスト（69判断）  →  1回目の推測で 8/8
8人ぶん552判断を並列で 0.85秒。手で書いたラベルは0個。
```

98問のうち29問は公式データの6項目から機械的に決まり、残り69問はJevが0.1秒で埋める。
**新キャラが来たら、6項目だけ入れれば当日から遊べる。**

### 手で遊んだ実測
甘雨を思い浮かべて答えたところ **7問**で当たった。
星5 → 体格 → 古参か → 璃月か → 長柄武器か → 氷か → 「甘雨ですね？」。
返事は「うん星5だよ」「かなり初期からいる」のような自由文で、Jevが0.15〜0.48秒で5択に落とした。

## 分かったこと
- **Jevは自分が知らないことを、確信度では十分に教えてくれない。**
  確信0.7以上に絞ると全体では89%正解だが、新キャラには確信60%で間違える例がある
  （オデット=水60%、ドゥリン=岩60%）。前作の「閾値で切れば効く」はここでは弱かった。
- **前作との違いは知識の鮮度。** 一般常識（タコ、富士山、織田信長）は動かないのでJevに任せられたが、
  毎月キャラが増えるドメインでは、Jevに知識を任せた時点で新しいものが全部死ぬ。
- **正解が手に入る事実は、Jevに聞かずにデータベースから入れる。** それだけで 68% → 100%。
- 主観69問（髪の色、性格、役割、人気）は公式データに無く、人が118人ぶん書くと約8,000ラベル。
  Jevは8,142判断を3.3秒で埋める。ここは置き換えが効いている。

## 使い方

```bash
pip install typesafe-sdk numpy      # TYPESAFE_API_KEY は環境に設定済み

python3 make_ground.py       # 公式データから正解表を作る（118人）
python3 knowledge_check.py   # Jevが原神をどれだけ知っているか測る
python3 build_tables.py      # 知識表を2種類作る
python3 gplay.py             # 対話で遊ぶ
python3 gstep.py --kv "星5=うん,元素_氷=氷だね"   # 1手ずつ進める
python3 gautoplay.py 0.0     # 全118人を出題して2つの表を比べる
python3 era_breakdown.py     # 実装時期で切る
python3 learn_new.py         # 新キャラを足す実演
```

データ元: https://gi.yatta.moe/api/v2/{en,jp}/avatar （Project Amber）。
`av_en.json` / `av_jp.json` として同梱してあるので、更新したいときだけ取り直す。
